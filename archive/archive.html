ZIP archives save text, code and tables. Images are not downloaded. Only the current saved response branch is exported; PDF and Working / Thinking are not included.

1. Load available chats

No history request is made until you click Load list. Keep the source ChatGPT tab and this archive tab open. You can read other tabs.

The list comes from ChatGPT. Project chats may be missing; compare the result with your account before relying on “all”. Deleted or unavailable chats cannot be recovered.

2. Select chats

20 chats per page. Scroll inside the list to see every row; use Previous / Next for more pages. Your selection stays checked across pages.

3. Save ZIP

ZIP parts save to Downloads automatically. A failed chat is skipped; if reading stops, completed chats are still saved when downloading is available. Each ZIP has an index.html and a manifest. The JSON report lists saved, failed and unattempted chats.
