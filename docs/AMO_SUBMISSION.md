# Mozilla Add-ons submission notes

**0.5.9 is Mozilla-signed (November 27, 2026).** All 46 runtime files match the tested submission, allowing equivalent manifest formatting and five added signature files only. The [submission record](AMO_SUBMISSION-v0.5.9.md) covers matching source, byte-identical reproduction and 318 automated tests. Permissions and host scopes are unchanged from 0.5.8.
