## Content and scope

All conversations and statistics shown are fictional demonstrations. Product screens are captured from the packaged menu/archive HTML and CSS with synthetic state in a fresh, isolated Firefox profile. The sample HTML document is generated by the production renderer with fictional text and an original SVG orbit illustration. The oversized report graphic is a promotional illustration, not a pixel-for-pixel claim about the app layout. Personal browser tabs and conversations are not used. The video is labelled **0.5.6 feature preview**, as signing is pending at creation time. It makes no measured speed or universal-completeness claim.

ZIP is explicitly identified as text-only; images and PDF are excluded from bulk ZIP. PDF parts require individual printing. Direct export and numbered parts are identified as ChatGPT features where applicable. Image controls do not claim original-download quality.

## Reproduce or edit

`capture.cjs` uses Node.js, the installed Firefox executable and a new local profile to render fixtures. It serves only synthetic pages and required project assets on loopback. It does not connect to ChatGPT. `render.py` uses Python, Pillow, NumPy, installed Windows Segoe UI/Consolas fonts and FFmpeg on PATH. Font files are not distributed.

```powershell
node promo/0.5.6/capture.cjs
python promo/0.5.6/render.py --preview
python promo/0.5.6/render.py
```

The renderer pipes frames to FFmpeg and does not write thousands of temporary frame files. Edit `STARTS`, `CAPTIONS` and the eight scene functions for timing, copy and layout. The original music is synthesized locally from oscillators and seeded noise.

## Verification

The encoded file decodes completely without FFmpeg errors. ffprobe confirms 60.000 seconds, 1920×1080, 30 fps, H.264 and stereo 48 kHz AAC. Encoded frames from all eight scenes were visually inspected. Audio analysis reports mean −17.8 dBFS and peak −4.0 dBFS, with no clipping. No claim of a live account export or a real performance benchmark is made.
