# Changelog

## 0.2.0 — 2026-08-18

- Renamed the extension to Dialogue Export.
- Added a stable Firefox extension ID.
- Declared that the extension collects no data.
- Raised the minimum supported Firefox version to 142.
- Prepared the project for GitHub and Mozilla Add-ons packaging.
- Added project documentation, privacy information, and third-party notices.
- Replaced unsafe `innerHTML` assignments with DOM operations.
- Passed Mozilla validation with 0 errors and 0 warnings.
- Added a Mozilla-signed XPI for permanent installation.

## 0.1.7 — 2026-08-17

- Added the Matrix-green visual theme and conversation timeline.
- Added the message-download toolbar icon.
- Improved export of writing blocks and embedded text.
- Added equal-sized, individually colored format buttons.
- Added independent background export and PDF printing.
